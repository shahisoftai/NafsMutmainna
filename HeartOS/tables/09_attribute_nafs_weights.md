# `attribute_nafs_weights` — The Attribute Nafs-Bias Matrix

> The 200×4 matrix that tells the scoring engine how much each attribute biases the Nafs vector.
> **Source:** `HeartOS/03_nafs_engine/attribute_nafs_weights.md`, editorial pass
> **Constraint:** Each row's 4 values sum to 100 (±5)
> **Generated:** 2026-06-12

---

## Schema

| Col | Type | Notes |
|---|---|---|
| `Attribute_ID` | INTEGER PK + FK → `attributes` | 1:1 with attributes |
| `Ammarah` | REAL | 0–100 |
| `Lawwamah` | REAL | 0–100 |
| `Mulhamah` | REAL | 0–100 |
| `Mutmainnah` | REAL | 0–100 |

**Constraint:** the four values sum to **~100** (within ±5).

---

## Rules Applied

1. **Sum to 100** — probability distribution.
2. **Negative attributes** (IDs 1–70): skew toward **Ammarah**.
3. **Positive attributes** (IDs 71–200): skew toward **Mutmainnah**.
4. **Hub virtues** (Ikhlas, Ihsan, Tawhid Kamil, Siddiqiyyah, Wilayah): `0/2/18/80`.
5. **Core virtues** (Sabr, Shukr, Tawakkul, Yaqin, Sakinah, Ridha): `1/4/25/70`.
