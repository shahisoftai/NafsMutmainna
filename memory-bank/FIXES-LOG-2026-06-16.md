## Fix 1 — Home: "From your last 15 days" section disappeared

### Root Cause (3 layered bugs)

**Bug A — `parseAllahNames` key mismatch** (`daily_dhikr_resolver.dart:535`)
- Seed data uses hyphenated English transliteration: `"Al-Halim;Ar-Rahim;Ar-Rafiq"`
- `_allahNamesData` lookup map uses Arabic-style camelCase keys: `"AlḤalīm"`, `"ArRaḥīm"`
- `_normalizeAllahNameKey()` stripped hyphens but didn't match the seed format
- **Result:** `parseAllahNames()` returned empty list → `dhikr.history.isEmpty` → section hidden

**Bug B — Provider never reloaded after check-in** (`checkin_screen.dart:52` + `daily_dhikr_view_model.dart`)
- Only `homeViewModelProvider` was invalidated after check-in
- `dailyDhikrViewModelProvider` never updated — section stayed stale until app restart

**Bug C — Stale seed data invisible to `_needsReseed`** (`app_database.dart:223`)
- `_needsReseed` only checked if tables were *empty*, not whether `Recommended_Allah_Names` was populated
- Databases seeded from an older `emotions_seed.json` (before Allah Names were added) had rows with empty strings — `_needsReseed` returned `false` → re-seed never ran

### Fixes Applied

**Fix A — `_englishNameToKey` lookup map** (`daily_dhikr_resolver.dart:155`)
Added a new `const Map<String, String> _englishNameToKey = {…}` that maps every English transliteration form from `emotions_seed.json` to the camelCase key in `_allahNamesData`. `parseAllahNames()` now looks up directly in this map first.
```dart
// Also added key for Ash-Shahid (was missing in initial version)
'As-Shahid': 'AsShahīd',
'Ash-Shahid': 'AsShahīd',
```

**Fix B — Auto-load in ViewModel + invalidation after check-in**
- `daily_dhikr_view_model.dart`: Added `load()` call in `DailyDhikrViewModel` constructor so any provider invalidation (e.g. after check-in) auto-triggers a reload
- `checkin_screen.dart:57`: Added `ref.invalidate(dailyDhikrViewModelProvider)` after check-in so the section updates without app restart

**Fix C — `_needsReseed` extended** (`app_database.dart:228`)
```dart
// Now also checks for empty Recommended_Allah_Names
final emptyNames = Sqflite.firstIntValue(
  await db.rawQuery(
    "SELECT COUNT(*) FROM emotions WHERE Recommended_Allah_Names IS NULL OR Recommended_Allah_Names = ''",
  ),
);
if (emptyNames != null && emptyNames > 0) return true;
```

**Fix D — Widget: always show empty-state hint** (`daily_dhikr_section.dart:131`)
Changed `else if (dhikr.hasAnyCheckins)` to `else` so "Your 15-day pattern will build as you check in." text always shows when history is empty (not gated on prior check-ins).

## Fix 2 — Heart Analysis: "No attributes detected"

### Root Cause
**FK constraint cascade failure in seed batch** (`seed_loader.dart:38`)
- `attributes` table has 183 rows (IDs 1–183)
- `attribute_nafs_weights_seed.json` had 200 rows (IDs 1–200) — 17 invalid IDs (184–200)
- All 4 link tables also had invalid references to IDs 184–200
- `db.batch()` used one transaction — one FK violation on row 184 rolled back the ENTIRE batch
- `seedAll` crashed before reaching `emotion_attribute_links` → table empty
- `compute_daily_nafs` found no emotion→attribute links → `result.detected` empty → Heart Analysis showed "No attributes detected"

### Fix Applied

**Fix E — Per-row insert in `_insertBatch`** (`seed_loader.dart:38`)
Replaced batch transaction with individual `db.insert()` calls wrapped in try/catch. One FK violation now skips only that row; all valid rows commit. Remaining tables seed normally.

```dart
static Future<void> _insertBatch(DatabaseExecutor db, String table, List<Map<String, Object?>> rows) async {
  if (rows.isEmpty) return;
  var inserted = 0, skipped = 0;
  for (final row in rows) {
    final cleaned = {...};
    try {
      await db.insert(table, cleaned, conflictAlgorithm: ConflictAlgorithm.replace);
      inserted++;
    } catch (e) {
      skipped++;
      Logger.warning('Seed: skipped $table row — $e');
    }
  }
  if (skipped > 0) {
    Logger.info('Seed $table: $inserted inserted, $skipped skipped (likely FK violations)');
  }
}
```

**Fix F — Pruned invalid rows from 4 link seed files** (data-only, no code)
| File | Before | Removed | After |
|---|---|---|---|
| `assets/data/attribute_nafs_weights_seed.json` | 200 rows | 17 (IDs 184–200) | **183 rows** |
| `assets/data/emotion_attribute_links_seed.json` | 285 rows | 4 (IDs 198, 200) | **281 rows** |
| `assets/data/attribute_links_seed.json` | 218 rows | 16 (IDs 184–198) | **202 rows** |
| `assets/data/domain_attribute_links_seed.json` | 229 rows | 21 (IDs 184–200) | **208 rows** |

Original files backed up as `.bak`. All primary keys unique, all FK references now valid.
