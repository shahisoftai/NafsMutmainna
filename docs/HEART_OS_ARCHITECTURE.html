1 · The 4 Layers

🟡 Knowledge Layer

Static Islamic content (seed once).

  • attributes — 200 records
  • emotions — 50 records

🟣 Graph Layer

Relationships & intelligence.

  • emotion_attribute_links
  • attribute_links (Heart Graph)
  • domains — 10 records
  • domain_attribute_links
  • domain_emotion_links

🟢 Nafs Layer

Spiritual-state calculations.

  • nafs_states — 4 records
  • attribute_nafs_weights
  • emotion_nafs_weights

🔵 User Layer

Daily activity & history.

  • checkins
  • detected_attributes
  • nafs_history
  • interventions_history
  • habits
  • habit_logs

⚪ Optional / Future

Add later without redesign.

  • master_pathways
  • user_goals
  • milestones

3 · Data Flow (User Journey)

1

User — Daily Check-In

User selects an emotion + intensity + optional notes → checkins

▼
2

Emotion → Attributes

Lookup emotion_attribute_links by Emotion_ID → affected attributes

▼
3

Attributes → Growth Path

Traverse attribute_links (Heart Graph) to find cure / next-step attribute

▼
4

Domain Analysis

Use domain_attribute_links + domain_emotion_links to surface the top 10 domains affected

▼
5

Nafs Calculation

Multiply emotion/attribute by attribute_nafs_weights / emotion_nafs_weights → write to nafs_history

▼
6

Recommendations

Pull Quran · Hadith · Dua · Allah Names for the target attribute → log in interventions_history

▼
7

User Feedback → 15-Day Nafs Meter

Rolling window over nafs_history renders the Ammarah → Mutmainnah meter

Example trace — User feels Ghadab (anger) at intensity 7:

1. Insert into checkins
2. emotion_attribute_links returns Ghadab + Sabr (Disease + Treatment)
3. attribute_links graph returns path: Ghadab → Sabr → Hilm → Rifq → Rahmah
4. domain_attribute_links classifies these as Character + Relationships
5. emotion_nafs_weights on Ghadab → Ammarah +0.6, Lawwamah +0.3
6. Show "Patience verses" + dua for Sabr, log to interventions_history
7. After 15 days of consistent check-ins, Nafs meter shifts toward Mulhamah
